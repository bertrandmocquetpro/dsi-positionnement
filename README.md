# Auto-positionnement DSI-DSIN ESR

Application HTML/CSS/JavaScript statique, compatible GitHub Pages.

## Déploiement rapide

1. Déposez les fichiers dans un dépôt GitHub.
2. Activez GitHub Pages : Settings → Pages → Deploy from a branch → `main` → `/root`.
3. Ouvrez l’URL GitHub Pages.

## Contenu

- 30 situations professionnelles contextualisées ESR.
- Scoring sur 6 axes dérivés du référentiel DSI-DSIN.
- Graphe radar avec Chart.js.
- Export PDF, CSV et JSON.

Les résultats restent dans le navigateur, sauf export volontaire.
